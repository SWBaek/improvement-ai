# CASE-001 Baseline: 연구 브리프 파악

## 검토 과제

팀은 내부 문서 검색 품질을 개선하기 위해 문서 metadata 정비 실험을 검토하고 있다. 검토자는 실험의 목적, 현재 근거, 한계와 다음 행동을 이해해야 한다.

## 현재 내용

최근 30개의 실패 검색을 표본으로 확인했으며 18개는 문서 제목이나 tag가 실제 검색어와 달랐다. 7개는 오래된 문서가 상위에 노출됐고 5개는 접근 권한 때문에 결과를 열 수 없었다. 이 표본은 한 팀의 2주 기록만 포함하므로 전체 조직을 대표하지 않는다. 제안은 문서 50개에 표준 title, owner, updated-at과 topic tag를 적용한 뒤 같은 질의를 다시 실행하는 것이다. 성공 기준은 실패 검색 30개 중 20개 이상에서 원하는 문서가 상위 3개 안에 나타나는 것이다. 아직 검색 엔진 자체를 교체하거나 전체 문서를 일괄 수정하지 않는다.

검토자는 목적과 범위를 이해했다면 확인하고, 불명확한 부분이 있으면 의견으로 남긴다.

## 정답 기준

- 목적: metadata 정비가 검색 품질을 개선하는지 확인
- 범위: 문서 50개와 기존 실패 검색 30개
- 한계: 한 팀, 2주 표본
- 다음 행동: metadata 적용 후 동일 질의 재실행
