# Artifact Trigger Decision

- 상태: Accepted Research Baseline
- 기준일: 2026-08-06

## 기본값

대화는 기본 상호작용 수단이다. HTML Review Artifact는 대화를 예쁘게 다시 보여주기 위해 생성하지 않는다.

## 생성 조건

다음 조건 중 하나 이상이 있고, 구조화된 표현이 판단 비용을 실제로 낮출 때 Artifact를 생성한다.

- 둘 이상의 대상이나 대안을 동일 기준으로 비교해야 한다.
- 대화가 길어 현재 상태, 미결 항목 또는 결정 대상이 흐려졌다.
- 특정 revision에 대한 승인, 거부, 보류 또는 변경 요청이 필요하다.
- 주장, 근거, 가정, 위험이나 불확실성을 함께 봐야 한다.
- diff, 비교표, 검증 결과처럼 선형 텍스트보다 적합한 표현이 필요하다.
- 인간 응답을 target과 연결해 AI의 후속 작업으로 전달해야 한다.

## 생성하지 않는 조건

- 짧은 사실 질문과 단일 답변
- 아직 목표나 질문 자체가 정해지지 않은 탐색 초기
- 응답을 구조화해도 후속 행동이 달라지지 않는 안내
- 최신 상태를 보존할 필요가 없는 일회성 설명
- Artifact 생성 비용이 검토 비용보다 큰 단순 변경

## 생성 시점

Artifact는 discussion snapshot이다. AI는 다음을 먼저 명시할 수 있을 때만 생성한다.

1. 하나의 주된 human goal
2. 검토할 안정적인 target
3. 판단에 필요한 최소 context
4. 허용할 response action
5. interaction 완료 조건

이를 정할 수 없으면 대화를 계속한다.
