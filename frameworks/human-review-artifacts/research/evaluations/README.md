# Human Review Evaluations

직접 인간 검토 결과를 비민감한 요약으로 기록합니다. 원본 대화, 개인 식별 정보와 브라우저 telemetry는 저장하지 않습니다.

## 평가 양식

- 사례와 Artifact revision
- 수행한 과제
- 생성된 Response의 schema 및 Artifact 교차 검증 결과
- 목적 이해도: 1-5
- 정보 탐색성: 1-5
- 행동 명확성: 1-5
- target/revision 명확성: 1-5
- 응답 표현 충분성: 1-5
- 중대한 모호성
- 개선 의견
- 재검토 결과

## 합격 기준

- 모든 사례에서 유효한 Response를 생성한다.
- target 또는 revision 혼동이 없다.
- 중대한 행동 모호성이 없다.
- 각 평가 항목의 평균이 4.0 이상이다.
- 2점 이하 항목이 없다.

평가가 수행되기 전에는 readiness를 완료로 표시하지 않습니다.

첫 평가 절차는 [`session-001-instructions.md`](session-001-instructions.md)를 따릅니다.
