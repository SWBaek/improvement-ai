기술 결정 문서 정책 변경

피드백 반영과 검증 기준 충족은 서로 다른 판단입니다.

변경 전

자유로운 Markdown 형식이며 변경 이력 규칙이 없습니다.

변경 후

`DEC-XXX`, 상태, 날짜, 결정·이유·결과와 `supersedes`를 요구합니다.

피드백 반영

  • ID 추가
  • 상태와 날짜 필수화
  • 대체 관계 추가
  • 참조 검증 추가

검증 결과

  • 정상 결정 통과
  • 중복 ID 거부
  • 알 수 없는 대체 대상 거부
  • 날짜 누락 fixture 미실행

현재 결론: 전체 합격 기준 미충족
