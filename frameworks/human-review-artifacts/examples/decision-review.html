Core 전달 형식 결정

범용 Artifact를 단일 HTML로 전달할지, JSON과 HTML을 분리할지 비교하고 결정하는 중립 예시입니다.

표시 필터

요약

두 파일을 동기화하는 운영 부담을 피하면서도 기계 판독성을 확보하는 전달 형식을 결정해야 합니다.

현재 결정 단일 HTML 안에 최소 JSON Manifest를 포함하는 방안을 우선안으로 검토합니다.

주요 내용

사실 브라우저는 별도 build 없이 로컬 HTML 파일을 표시할 수 있습니다.
가정 대부분의 Artifact는 완전한 domain 데이터 모델 없이도 semantic HTML로 충분히 검토할 수 있다고 가정합니다.
제안 실제 내용은 HTML에 두고 식별·상태·provenance만 내장 Manifest로 관리합니다.
위험 Manifest와 화면에 중복 노출되는 제목·상태가 어긋날 수 있으므로 validator가 일치 여부를 검사해야 합니다.

검토 요청

기본 전달 형식을 선택하고 결정에 필요한 후속 조건을 기록해 주세요.
