# Research

`docs/research/`는 Blueprint 전략과 저장소 운영을 판단하기 위한 조사 기록이다. 채택된 ADR이나 Blueprint 계약이 아니며, 조사 시점의 공개 자료를 근거로 관찰과 추론을 구분한다.

## Reports

| Report | 조사 범위 |
|---|---|
| [AGENTS.md size guidance](agents-md-size-guidance.md) | 공식 AGENTS.md 형식과 Codex, Claude Code, Cursor 문서의 크기 한도·권장을 비교하고 루트 always-on 예산을 평가 |
| [Karpathy LLM Wiki ecosystem](bencmark/karpathy-llm-wiki-ecosystem.md) | `llm-wiki.md` 이후 Idea File, Skill, framework, CLI, Plugin과 App 구현을 비교하고 Blueprint-only 전략을 평가 |
| [Private Remote Artifact Preview market](bencmark/private-remote-artifact-preview-market.md) | private network, public tunnel, IDE forwarding, remote workspace와 framework별 preview 제품을 비교하고 AI orchestration의 시장 공백을 평가 |
| [Deletion avoidance and rule inversion](deletion-avoidance-and-rule-inversion.md) | 삭제 지시가 부정문·가드로 남는 습관을 코드 편집 측정과 부정 회로 연구로 구분하고 공통 원인을 평가 |
